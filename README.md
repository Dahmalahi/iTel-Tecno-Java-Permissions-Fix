 How to Solve Infinite Yes/No Permissions on iTel/Tecno

Requirements:
📦 Moby Explorer  
🎮 A Java app or game that always asks for permissions (for example BlueFTP or Mini Commander)
## Download Links
- [Moby Explorer](https://david2me.free.nf/app.php?file=1777667427_c98b9d9e5a02ff44.jar)
- [Mini Commander](https://david2me.free.nf/app.php?file=1776155335_832986b138f5f1e4.jar)

Step 0:
⚙️ Install Moby Explorer.  
⚙️ Install BlueFTP or Mini Commander.  
🛡️ Install a Java app or game that will act as a sacrifice.  
⚠️ Note: If you install the app you want to fix last, it will corrupt the others.  
That is why you must install a sacrificial app or game last, then delete it later.

Step 1:
📱 Open JVM, select BlueFTP, press Left Soft Key (LSK).  
🔧 Go to Application Settings, Permission Settings, Local Connection, Always Allowed.  
↩️ Return to the installed Java apps list.

Step 2:
📂 Open Moby Explorer, go to TFCard, java, installed, selector.utf.  
✏️ Press LSK, choose Text Editor.  
🔍 Find the line:  
fg_permissions=SAOOSOO  
✏️ Change it to:  
fg_permissions=AAAAAAAA  
💾 Save and close.

Step 3:
🗑️ Delete the sacrificial app.  
✅ Now your Java app will only ask once for Yes/No permission.
